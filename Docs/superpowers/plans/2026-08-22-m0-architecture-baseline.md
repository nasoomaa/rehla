# M0 — Architecture Baseline and Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bootstrap the Laravel 13 application, monorepo package workspace, and CI pipeline that every subsequent Rehla milestone depends on.

**Architecture:** Install a stock Laravel 13 application at the repo root. Create `packages/rehla/<name>/` stubs for all 17 V1 packages with correct `composer.json`, autoload, and `ServiceProvider` files. Register them as Composer path repositories in the root `composer.json`. Wire Pest + Orchestra Testbench, write Pest `arch()` tests that enforce the DAG invariants from the master spec, and create a GitHub Actions CI workflow that runs tests on push.

**Tech Stack:** PHP 8.5+, Composer 2.9+, Laravel 13.x, Pest 3.x, Orchestra Testbench, GitHub Actions

**Spec:** `Docs/superpowers/specs/2026-08-22-rehla-platform-design.md`

## Global Constraints

- PHP >= 8.5.4 (no lower)
- Composer >= 2.9.5
- Laravel 13.x — never Laravel 12 or 11
- PostgreSQL as primary database (driver: `pgsql`)
- Package paths follow `packages/rehla/<name>/` exactly — no deviation
- Composer package names follow `rehla/<name>` — e.g. `rehla/core`
- No business logic in M0 — no Models, no migrations, no domain classes
- No Eloquent usage in M0 tests (DB not connected)
- Pest (not PHPUnit directly); Orchestra Testbench for package tests
- All protected Admin routes must be mapped to ACL — CI gate (not configured until M4, but the Pest arch test stub must exist now)
- Blade + Tailwind CSS + Alpine.js + Vite (frontend scaffold deferred to M4; only Vite dependency scaffolded here if present in the base Laravel install)
- Testing: `./vendor/bin/pest` — the CI script must use this exact binary
- `APP_ENV=testing` in CI

**Interfaces:**

  ```bash
  ls /home/ubuntu/rehlla
  ```
  Expected: only `Docs/` directory and `.env` file. No `composer.json` yet.

- [ ] **Step 2: Install Laravel 13 into the current directory**

  ```bash
  cd /home/ubuntu/rehlla
  composer create-project laravel/laravel:^13.0 . --prefer-dist --no-interaction
  ```

  Expected: Composer installs Laravel 13. Creates `composer.json`, `app/`, `bootstrap/`, `config/`, `database/`, `resources/`, `routes/`, `storage/`, `tests/`, `vendor/`, `artisan`, `.env.example`.

  > If a `.env` already exists, the installer may warn or skip creating it. That is fine.

- [ ] **Step 3: Verify Laravel boots**

  ```bash
  php artisan --version
  ```
  Expected output: `Laravel Framework 13.x.x`

- [ ] **Step 4: Set application key**

  ```bash
  php artisan key:generate
  ```
  Expected: `APP_KEY` set in `.env`.

- [ ] **Step 5: Update `.env` for PostgreSQL**

  Open `.env` and ensure:
  ```ini

  DB_PASSWORD=
  ```

- [ ] **Step 6: Update `.env.example` to match (this file is committed)**

  Ensure `DB_CONNECTION=pgsql` in `.env.example`.

- [ ] **Step 7: Verify `.gitignore` excludes `.env` and `/vendor`**

  Laravel's default already has both. If missing, add:
  ```
  /vendor

  ```

- [ ] **Step 8: Commit the Laravel skeleton**

